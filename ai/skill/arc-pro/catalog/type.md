# Type

## `keycap-keyboard` — Keycap keyboard (Pro, special)

Mechanical keycaps that sink and light up as you type, with the text above the board.

When to use:
- Landing pages for keyboard-first products and developer tools.
- Onboarding that teaches shortcuts by lighting the keys they use.

When not to use:
- Form input; use a real text field.
- On-screen keyboards for accessibility needs; use the platform's.

Keywords: special, keyboard, motion, new, mechanical keyboard, keycap animation, 3d keyboard react, keyboard component, typing animation, key press effect, virtual keyboard

Files: demo.module.css, demo.tsx, keycap-keyboard.module.css, keycap-keyboard.tsx

## `sand-text` — Sand text (Pro, special)

A headline made of sand that pours into the letters, crumbles where the cursor digs, and heals itself.

When to use:
- A hero headline or section title that should be fun to touch.
- Short words that change on a selection, like a product name or theme.

When not to use:
- Body copy or long headings; use in-view-title or text-reveal.
- Text that must stay readable while people interact near it, like form labels.

Keywords: text, canvas, physics, new, sand, falling sand, cellular automaton, particles, text effect, headline, crumble, hourglass

Files: demo.tsx, sand-text.module.css, sand-text.tsx

## `typewriter-terminal` — Typewriter terminal (Pro, special)

A terminal that types a scripted CLI session with a seeded human cadence, colors the shell syntax, and streams output lines, progress bars and spinners, with a scrubber, play/pause and replay controls.

When to use:
- A landing page hero or install section for a developer tool, SDK, or CLI.
- Docs quick starts that show what each command prints before people run it.

When not to use:
- Use code-block for commands and source that people need to read and copy without waiting.
- Use log-stream for real, live output from a running process.

Keywords: special, motion, terminal, new, typewriter, cli, install, command line, shell, typing animation, npm, developer tools, replay, scrubber

Files: demo.tsx, typewriter-terminal.module.css, typewriter-terminal.tsx
