# Free registry · foundation

## `arc-foundation` · Arc foundation (Free, component)

Arc design tokens (color, surface, radius, shadow, accent, focus, light and dark themes), plus the shared motion presets. Install once per app.

Keywords: foundation, arc, foundation

Files: registry/foundation.css

## `arc-motion-tokens` · Arc motion tokens (Free, component)

The shared motion presets (durations, easings, springs, staggers) Arc components import. Installed automatically with any item that uses them.

Keywords: foundation, arc, motion, tokens

Files: registry/motion-tokens.ts, lib/motion-tokens.ts
