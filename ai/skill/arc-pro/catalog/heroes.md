# Heroes

## `comparison-table` — Comparison table (Free, block)

An us versus them table with a sticky header, a highlighted column, and a stacked phone view.

When to use:
- Showing how your product stacks up against named alternatives.
- Feature matrices with three to five columns and grouped rows.

When not to use:
- Use plan-comparison to compare your own pricing tiers.
- Use a sortable data table for large datasets.

Keywords: comparison table, us vs them, competitor comparison, feature comparison, alternatives page, sticky header table, react comparison table

Files: registry/blocks/comparison-table/comparison-table.tsx, registry/blocks/comparison-table/comparison-table-data.ts, registry/blocks/comparison-table/comparison-table.module.css

## `logo-marquee` — Logo marquee (Free, block)

A quiet, continuously moving row of brand marks with a pause control.

When to use:
- A customer or integration logo strip on a landing page.
- Social proof sections with a heading and a short supporting line.

When not to use:
- Use integrations when each logo needs a description or a connect action.
- Use testimonial-stage when quotes matter more than logos.

Keywords: react logo marquee, logo cloud, infinite logo scroll, trusted by logos, customer logos strip, css marquee

Files: registry/blocks/logo-marquee/logo-marquee.tsx, registry/blocks/logo-marquee/logo-marquee.module.css
