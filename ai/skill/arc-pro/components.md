# Choosing an Arc component or block

Pick the item whose job matches, not the one that looks closest. Every id below is a real item in
this repository: live preview at `/components/<id>` (`/components/blocks/<id>` for blocks), docs at
`public/docs/<id>.md`, and — for Pro items — the reconstructed source at `src/components/arc/<id>/`.

`tier` only says where an item came from. Here **every** item is usable: Pro source is already
vendored, so there is no account, token or install step. Ask for the item you want, read its
"When not to use", then copy the files.

## How to decide

1. Name the job in one line ("pick one of three plans", "confirm deleting a project").
2. Look it up with `search_components`, or scan the groups above.
3. Open the group file in `catalog/` for the reason to use and not to use each item, or call `get_component`.
4. Follow the "not for" line: it names the better alternative.
5. Prefer a block for a whole region, a component for a single control. Replace sample data.

## Wiring rules

- Inside this repo: `@/components/arc/<id>/<id>` and `@/components/arc/<id>/<id>.module.css`.
- Elsewhere: copy the item folder, keep relative imports, import `foundation.css` once.
- Shared parts (`button`, `input`, `select`, `popover`, `segmented-control`, `text-morph`, `tooltip`, `lib/`) live in `src/components/arc/` as well.
